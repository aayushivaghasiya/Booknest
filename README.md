# BookNest — Premium Online Book Store

A responsive online book store built with HTML, CSS, JavaScript and Node.js/Express.

## Features
- Premium responsive storefront design
- Search by title, author and category
- Multiple book categories and category chips
- Sorting by price and rating
- Book details modal
- Add to cart, quantity controls and remove items
- Sign in / create account demo using localStorage
- Secure-style checkout with address and payment options
- Successful order confirmation with order ID and delivery date
- Order history and return/exchange request flow
- Admin book management (add, edit, delete, stock)
- LocalStorage cart and order persistence
- Express API for books, categories and checkout

## Run
1. Install Node.js.
2. Open this project folder in VS Code.
3. Run `npm install`
4. Run `npm start`
5. Open `http://localhost:3000`

The checkout/payment UI is a frontend/demo flow; it does not process real payments.
